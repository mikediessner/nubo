Citation
========

If you are using NUBO for your research, please cite as:  

    M Diessner, KJ Wilson, and RD Whalley. "NUBO: A Transparent Python Package
    for Bayesian Optimisation," *Journal of Statistical Software*, vol. 114,
    no. 1, p. 1-28, 2025, doi: 10.18637/jss.v114.i01.
